## Specific source caveats

- A website from a sibling project is evidence of what that author reports, not proof of organizer scoring, methodological validity, or raster uniqueness.
- The live official leaderboard should be opened directly by a user who is entitled to access it. This project does not run a polling job or keep a copied score table.
- The public USGS DEM catalog establishes a public source exists; it does not establish that the exact competition tiles are already in this checkout or that every candidate input is correctly aligned.
- No numerical holdout result exists for GEMSDOE66. The machine-readable run card records all unavailable metrics as `null`.
