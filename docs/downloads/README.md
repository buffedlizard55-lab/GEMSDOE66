# Candidate downloads

**No H66 GeoTIFF or ZIP is cleared for download or competition submission.** This directory intentionally contains no raster artifacts.

The historical H66-1 files were moved to `evidence/archives/h66-1/` for audit continuity only. They are not validated against the authorized official footprint, have no complete registry clearance, and must not be treated as submission candidates. The earlier `[0,1]` portal rejection cause is unknown; no fix is claimed.

The public site links a candidate only if the single canonical card at `docs/data/run-card.json` records every release gate as passed, `promote=true`, and a matching file/hash under this directory. A local writer or validator receipt by itself does not clear a file.
