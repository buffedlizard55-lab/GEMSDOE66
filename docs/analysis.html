Conditional mechanism—not a result

Owner material describes H33-2-B2 as a post-processing/pruning variant that removes predictions near mapped catalogue faults. Under the published distance-weighted Tversky objective, removing unsupported emissions could reduce false-positive mass; removing predictions near a genuinely new labeled fault could instead reduce true-positive credit. Which effect dominates depends on the withheld labels and exact raster. No controlled experiment in this checkout tests that mechanism.

The scoring specification uses α=0.2, β=0.8, and a 300 m triangular distance kernel (S02). These are metric parameters, not an H33 score. The metric derivation documents assumptions in the local implementation; it does not recover the organizer's hidden labels.

Can a better result be demonstrated?

Not with the current evidence. The leading native-lidar hypothesis is a slope-aware scarp-template field joined with Steger ridge/valley and Frangi multiscale line evidence at 2–20 m, aggregated to 100 m. It has not been computed. Therefore there is no `HOLDOUT-DTI`, no confidence interval, and no basis for a submission file or slot.

A future demonstration would require: (1) the exact H33 submission receipt and byte-matched artifact to resolve attribution; and separately (2) the shared inputs/evaluator, preregistered segment-aware spatial holdout, leakage canaries, range-front check, and pre-/post-placement registry comparison for the new lidar candidate. Any measured score must be labeled `HOLDOUT-DTI` with evaluator version, withheld-positive count, and 95% CI.
