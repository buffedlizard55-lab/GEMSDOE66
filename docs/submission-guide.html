Release gates before any future download

  1. Inputs and provenance: authorized competition training features, labels, sample grid, exact DEM tile inventory, and verified shareable data lineage.
  2. Pre-implementation review: two independent scientific leads review the ranked hypotheses, geological mechanism, named mimics, and planned holdout.
  3. Valid science test: whole vector-defined fault segments withheld with a preregistered buffer; catalogue-derived features use visible faults only; visible faults are masked pixel-exactly; truth and scoring restricted to LiDAR-covered holdout blocks; pooled DTI and 95% spatial-block CI; off-range-front check.
  4. Leakage and novelty: each feature alone tested on the holdout; AUC above 0.90 is a stop pending explanation. Compare continuous pre-placement surfaces and final dots against the complete registry. An incomplete registry is not a pass.
  5. Official format: normalize to float32 [0,1], write EPSG:32611 on the exact official shape/transform, and use NaN only outside the official footprint. Run the validator with both reference and features rasters; no skipped checks count as a pass.
  6. Artifact receipt: record name, note, SHA-256, pixel agreement, validator output, run card, and all review sign-offs. Only after every gate passes may a one-click TIFF be published.

Portal steps once a candidate is cleared

  1. Use the download link on the project overview only after the run card explicitly changes to a cleared state.
  2. Open the DrivenData homepage and navigate manually to the GEMS Prize and its submission form. This project does not deep-link, automate, or monitor the platform.
  3. Upload the single-band TIFF or a ZIP containing exactly one TIFF, then use the run-card's unique name and short note. The project's field limit is 140 characters.
  4. Follow the current official rules: feedback submissions are limited to three per week, and one final entry must be selected.
  5. Include the required generative-AI disclosure in the submission narrative, describing the actual use across all submission materials. The text below is only a fill-in template.
Generative-AI disclosure (edit to match actual use): [Name the tool(s)]. I used generative AI to assist with [specific code, review, or documentation tasks] in developing [identify submission elements]. I independently checked [specific analyses, sources, and outputs]. The tools did not access private test labels or submit to the competition. [Correct every sentence to match what actually occurred.]

The official rules are the source of truth. The narrative template is not legal advice or a substitute for reading the current rules.
