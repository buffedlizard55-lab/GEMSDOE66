How to submit

Nothing in this guide is a file you can submit today. It describes the steps that apply once the holdout gate has been met.

Today: no file is offered.The holdout gate has not been run. Competition data is not in this environment.

2. Checks before any upload

# Place the official files in data/ first (manual download), then:
python scripts/verify_competition_data.py          # exit 0 = required files present

# Validate the candidate file against the official grid and footprint
python -m gems.validate_submission outputs/candidate.tif \
    --reference data/labels.tif --features data/training_features.tif
# exit 0 = all required checks PASS (SKIPPED checks are reported, not passed)

The validator refuses values outside [0, 1], NaN inside the footprint, a finite nodata tag, a wrong CRS, a wrong transform, and a wrong shape. The writer refuses to write without a reference raster.

3. Gate (required)

  1. Measure HOLDOUT-DTI on spatially blocked holdout blocks that are lidar-covered, not confined to range fronts.
  2. Record the evaluator version, withheld positive count and 95% CI in the run card.
  3. Run the leakage canary: any single feature with holdout AUC above 0.90 is leakage until proven otherwise.
  4. Check overlap with the registry rasters (python scripts/lane_check.py candidate.tif registry.tif; exit 2 = drift, exit 3 = inconclusive). Correlation above 0.90, or more than 70% of dots within 3 px of one registry raster's dots, means lane drift: log it as a duplicate and stop.
  5. Only if all of the above pass does the run card say promote.

4. Upload (manual, after the gate)

  1. Log in to DrivenData and open the submission page for competition 306.
  2. Choose the file, a unique name and a note of at most 140 characters. The writer embeds the name and note as GeoTIFF tags (GEMS_NAME, GEMS_NOTE) and in its receipt.
  3. Record the exact file name, SHA-256 and the receipt text. Copy the organiser's score only from the receipt, and label it ORGANIZER-CONFIRMED.

The submission form was not inspected (login required). Steps 1–3 are from the brief and the official rules; check the live form.

5. Do not

  • Do not submit a TIF copied from another team, a mirror, or an earlier submission. Rules A.5(1) require original work.
  • Do not commit competition data (data/, *.tif) to git. DrivenData's terms of use restrict redistribution.
  • Do not write a projection or a model estimate as a score.
