2H67-B Metric-native maximal-coverage emission
any belief surface; no new input layer		Greedy maximisation of the expected official DTI itself under an independent-Bernoulli truth model, with an exact closed form for the per-dot expected kernel credit. Replaces a fixed dot budget plus Poisson-disk thinning.It does not change which faults are believed; it changes how much of the alpha=0.2 budget is wasted on redundant dots. The calibration inversion gives x = (N-M)/|G| = 0.676 for the best prior family, i.e. two thirds of a truth-set's worth of emitted mass earns nothing.None - this is a placement rule, not a geological signal. Its failure mode is over-thinning, which the break-even rule bounds.Earlier sessions fix a dot count and then thin; none optimises the metric's own expectation, and none derives the per-dot expected credit in closed form.Low - 180 lines plus unit tests, already written and Monte-Carlo verified.implemented and unit-tested this session
