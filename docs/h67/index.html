What this project is

An auditable pipeline that produces one GeoTIFF of fault predictions for the DOE GEMS Prize (DrivenData competition 306). The scored truth is faults that are not in the public USGS database, so every design choice here targets that population rather than the 60,988 labelled pixels we were given.

The single most important measurement in this repository is the structure of the official metric. It is a budget, not a segmentation score: every emitted pixel costs α = 0.2 whether or not it earns credit. That is why the emitted file is a sparse dot set and not a dense probability map. See Method & metric.

This session's finding

95.2% of the USGS SGMC state-geologic-map fault pixels in the study area lie outside the given catalogue (79,615 of 83,593; 62,122 of them more than 300 m from any catalogue pixel). The given labels come from the USGS Quaternary fault database and INGENIOUS, so bedrock geologic-map faults are precisely the population that database omits — and precisely what an expert panel would add. No earlier session in this family emitted an SGMC-anchored candidate; the layer was carried as "proxy only, not used in the factorial".
