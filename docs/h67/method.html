Metric

Transcribed from the official problem page: k(d) = max(1 − d/300 m, 0), α = 0.2, β = 0.8,

TPw = Σg maxx p(x) k(d(x,g))
FPw = Σx: p>0 p(x) [1 − maxg k(d(x,g))]
FNw = Σg [1 − maxx p(x) k(d(x,g))]
DTI = TPw / (TPw + 0.2 FPw + 0.8 FNw)

Our implementation is checked three ways: it equals a literal O(N·M) brute-force transcription of those formulas to 3.6e-15 on random inputs; the identity TPw + FNw = |G| holds exactly; and the page's own worked example (5-pixel vertical truth crossed by a 5-pixel horizontal prediction) reproduces TPw = 3.00 and FNw = 2.00 exactly. The page states FPw = 1.89 where a literal reading of its own formula on a plain 5-pixel cross gives 2.00; that discrepancy is logged as IR-67-METRIC-01 rather than tuned away.

Emission: greedy maximisation of expected DTI

Read the belief surface b(x) as independent Bernoulli truth probabilities. Then

E[TPw](D) = Σx b(x) · maxy∈D k(d(x,y))
E[my] = ∫01 [1 − ∏j: kj>t (1 − b(j))] dt
E[DTI](D) = E[TPw] / (0.2 E[TPw] + 0.2 Σy∈D(1 − E[my]) + 0.8 Σb)

src/gems67/emit.py adds dots greedily while that ratio rises and stops by itself at break-even; the budget is only a safety cap. E[my] is exact under independence (accumulated in log space), and is verified against a 400,000-draw Monte Carlo in tests/test_h67_emit.py. Because k has 3-pixel support, each marginal gain is a 7×7 local sum.

Holdout

Whole fault segments are withheld with a 300 m buffer removed from the visible set only (src/gems/holdout.py). Every layer that reads the withheld pool is rebuilt from the visible faults alone, and an assertion fails the run if a withheld pixel is still reachable through one. Visible faults are masked out of the eligible set pixel-exactly, per protocol. 8-connected components are used as segment IDs and that proxy is disclosed.

Scale caveat, stated plainly

The brief asks for 2–20 m filters on native 1 m LiDAR. The finest reachable product in this environment is the owner's 100 m aggregate of 3DEP 1 m tiles, so the Frangi/Steger/ structure-tensor scales here are 200–2000 m. That is a deviation, not a fulfilment, and it is recorded as such rather than described as the native-resolution method.
